# 研究记录

`experiments.jsonl` 是追加式实验账本，记录每批获选候选的参数、训练分、验证分、验证分块、回撤、代码版本、数据版本、评分口径和成本假设。只接受已计入交易成本的结果，不接受冻结测试集成绩。数据、策略/回测代码、评分或成本假设任一变化时，必须先建立新基线。

`batches/` 保存每批所有候选的训练排行、唯一进入验证期的参数以及是否达到初始研究门槛。自动搜索有单批和单次运行预算；参数空间用尽或方向暂停后停止，不会自动调用 AI 或重设目标。默认参数范围只是待检验假设。

`proposals.jsonl` 保存 AI 提出的待验证假设。AI 建议不会自动修改代码、晋升策略或下单。

实验账本、批次报告和提案应随研究里程碑通过 `scripts/save_to_github.sh` 同步到 GitHub；原始行情、密钥和 Plus 登录凭证不得提交。
